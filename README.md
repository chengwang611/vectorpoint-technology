# VectorPoint Technology — AI & Fintech Website

A responsive, single-page static company website. Open `index.html` in a browser to preview.

## Core areas
- Enterprise Data Engineering
- Cloud Data Platforms (Azure / Databricks)
- AI Agents and LLM Applications (RAG, tool integration, human-in-the-loop)
- Fintech AI Solutions
- Architecture & Modernization
- AI-Ready Data Foundations

## Before going live
1. Replace the placeholder contact details with your real business email.
2. Check any service claims against offerings you can actually deliver.
3. Complete brand, trademark and operating-name checks.
4. Publish the three files to a static host, such as GitHub Pages or Cloudflare Pages.
5. Connect your custom domain once acquired.
